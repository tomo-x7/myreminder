# 科目別の見積もりと実績参照（#42）

## 選ぶ実績

科目を割り当てた課題は、同じ `courseId` の確定済み実績を最優先にする。種類・シリーズが異なっても同じ科目としてまとめる。教科・科目は同じ意味で、DB 上は `courses` の ID を使う。

1. 同一科目の有効な実績が1件以上あれば、その科目だけで予測する。シリーズを別に学習して上書きしない。
2. 同一科目の実績がない場合は、同じ種類、全体、固定事前分布へフォールバックする。
3. 科目なしの課題は、科目なしの同じシリーズがあれば種類・全体に続く縮小推定で使える。別科目に属するシリーズの実績は、このシリーズ枠に入れない。
4. 入力欄から参照する実績も同一科目を優先し、種類をまたいだ新しい順に最大3件返す。科目なしなら科目なしの同じシリーズ、次に種類を探す。実績を他の範囲から継ぎ足さない。

有効な実績は、見積もり・実績が有限の正数で、完了日時も有限のもの。完了課題の確定済みの作業時間を使い、確認待ちの作業記録を含む課題は除く。旧状態との互換性は完了状態の仕様に従う。名前・カテゴリによる科目の推測や統合は行わない。

## 学習の単位

同一科目の予測は、その科目のデータだけで重み・回帰・事後分布を求める。他科目の実績が増えても、当該科目の予測と不確かさは変わらない。科目内の種類は回帰の群にも分けない。

- 新しい順の順位 `i` に対して `w = 0.5^(i/15)`。半減期は科目内の実績件数で数える。
- `x = ln(見積もり)`、`r = ln(clamp(実績/見積もり, 0.2, 5))`。
- 基準の見積もり `c` は当該科目内の `x` の重みつき平均。
- 傾き `b = clamp((Σw dx dy + slopePrior)/(Σw dx² + slopePrior), 0, 1)`。`y = ln(実績)`、平均からの差を `dx, dy` とする。`slopePrior = 2(ln 2)²`。見積もりが全部同じなら `b = 1`。
- 基準の対数比 `z = r − (b − 1)(x − c)` を集計する。

同一科目が未学習の場合は既存の全体・種類の回帰と縮小推定を使う。その回帰でも科目を種類と交差させず科目単位の群とし、科目なしは種類の群とする。`shrinkK` はこのフォールバック階層で用い、独立した科目モデルの固定事前分布には用いない。

## 少数データと不確かさ

科目モデルは、固定事前分布 `μ0 = ln 1.3, σ0 = 0.5, κ0 = ν0 = 3` から一度だけ更新する。他科目の事後分布を科目の事前分布に使わない。同じ実績を全体・種類・科目・シリーズで重複更新しない。

`n = Σw, z̄ = Σwz/n, S = Σw(z−z̄)²` とすると、

- `κ = κ0 + n, ν = ν0 + n`
- `μ = (κ0μ0 + nz̄)/κ`
- `σ² = (ν0σ0² + S + κ0n(z̄−μ0)²/κ)/ν`
- 予測の尺度は `σ√(1 + 1/κ)`
- 計画用倍率は `exp(μ + tν(0.8) × 尺度 + (b−1)(ln 見積もり−c))` を `[0.2, 5]` に収める

少数データでは不確かさが残る。例えば、同一科目で「見積もり60分・実績30分」が3件だけなら、次の見積もり30分の中心は約24分、P80は約44分になる。旧方式の約28分とは異なり、3件を段階ごとに重ねて数えて確信を強めない。十分な実績があれば P80 が見積もりを下回ることは維持する。

## API と互換性

外部の引数・戻り値の形は変えない。`estimateBasis` の `course` 件数は種類・シリーズをまたいだ同一科目の有効件数を示す。同一科目がある場合、種類やシリーズを切り替えても同じ基準と件数になる。参照 API も `level: "course"` とし、その文脈は科目名だけを示す。

DB migration や既存実績の書き換えは不要。科目を変更した課題は、次回の取得時から現在の科目に属する実績として扱う。

## 検証条件

- 同一科目の実績を別種類からも参照・予測できる。
- 他科目の同じシリーズが大量に存在しても、同一科目を優先する。
- 他科目の実績が1000件増えても、科目内の重み・回帰・倍率・不確かさは不変。
- 少数実績は固定事前分布に寄り、増えるほど科目の値へ近づく。
- 科目なし・未知の科目・サンプルなしは定義した順にフォールバックする。
- 同一科目内の新しさ、入力順に対する決定性、不正サンプルの除外、倍率・傾きの範囲を維持する。
