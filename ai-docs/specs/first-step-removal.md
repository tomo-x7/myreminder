# 最初の一歩の廃止

issue #41。本人の指定により、「最初の一歩」の入力・表示と、通知本文の「まず:」を廃止する。

AI の文章・画像解析では、プロンプトの出力形式、規則、例、および JSON mode の Schema に `firstStep` を含めない。旧モデルの応答やキャッシュに `firstStep` が含まれても候補の正規化で `null` にする。締切・科目・見積もり・繰り返しの解析は従来どおり行う。

旧課題の保存済み `firstStep` は移行によって破棄する必要はないが、着手通知、締切前通知、危険通知の本文には使わない。通知の時刻・頻度・事実に基づく本文は変更しない。

互換性のため候補レスポンスと DB の nullable field は残す。新しい利用者向けの導線は作らず、旧データが再び通知文や画面に出ないようにする。
