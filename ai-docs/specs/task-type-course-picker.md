# 種類と科目の選択 (#53 / #54)

## 種類を一つにする

追加・確認・編集では「項目」と「種類」の二つを選ばせず、一つの「種類」でレポート・演習・小テスト・発表準備・その他・メモを選ぶ。

「種類」は「科目」と並べて配置し、独立した「項目」欄の行そのものを取り除く。タイトルと締切を先に入力できる順序とする。

保存形式は変更しない。メモは `taskKind: note`、ほかは `taskKind: work` と対応する `category` を送る。メモに切り替えただけでは元の category を消さない。通常の種類へ戻すときは taskKind と category を一度に更新し、入力済みの見積もり・通知設定・着手時刻は従来どおりフォーム内で保持する。保存済みの0分メモから通常の課題に変更した場合は、従来の既定値への復帰処理を使う。

## 科目はアプリ内のシートで選ぶ

現 main の追加カードはネイティブ `datalist`、編集フォームはネイティブ `select` を使っていた。Android Chromeで候補が一瞬で消える・離れた位置に出るとの本人の報告がある。ネイティブ候補ポップアップへの依存をなくすため、両方を共通の `CoursePicker` に置き換える。

「科目」の選択ボタンを押して選択シートを開く。シートには検索欄とその直下の候補一覧を置き、候補の一つか「なし」を選んだ時だけ確定する。入力欄のフォーカスや入力途中の候補更新だけでは閉じない。選択、閉じる、外側のタップ、Esc で閉じ、元のボタンへフォーカスを戻す。シートのフォーカスと画面内の配置は共通 `ActionSheet` に委ねる。

候補は科目名と別名を NFKC・大文字小文字・空白を正規化して絞り込む。一覧の各行には44px以上の高さを確保する。選択中はチェックと `aria-pressed` で伝える。候補の絞り込みで検索欄を作り直さず、入力中のフォーカスを維持する。スマホでは開いた直後に自動でキーボードを開かない。PCでは検索へフォーカスを置く。

選択済みの科目名はボタン内に表示し、長い名前は省略して幅をはみ出させない。追加カードの科目名は選択した登録科目の名前に更新し、保存時は既存の名前・別名解決で ID にする。編集フォームでは選択した ID を直接保存する。

AI が返した未登録の科目名は選択ボタンに表示し、既存の「未登録の科目」エラーを維持する。登録科目か「なし」を選び直せる。科目の新規登録機能は追加せず、未登録の名前は従来どおり科目なしで保存する。

補助の説明文・タグライン・セカンダリラベルは追加しない。スクリーンショットはリポジトリに含めない。
