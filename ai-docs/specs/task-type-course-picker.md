# 種類と科目の選択 (#53 / #54)

## 種類を一つにする

追加・確認・編集では「項目」と「種類」の二つを選ばせず、一つの「種類」でレポート・演習・小テスト・発表準備・その他・メモを選ぶ。

「種類」は「科目」と並べて配置し、独立した「項目」欄の行そのものを取り除く。タイトルと締切を先に入力できる順序とする。

保存形式は変更しない。メモは `taskKind: note`、ほかは `taskKind: work` と対応する `category` を送る。メモに切り替えただけでは元の category を消さない。通常の種類へ戻すときは taskKind と category を一度に更新し、入力済みの見積もり・通知設定・着手時刻は従来どおりフォーム内で保持する。保存済みの0分メモから通常の課題に変更した場合は、従来の既定値への復帰処理を使う。

## 科目の直接入力と補完

科目欄は直接入力できるcomboboxとし、途中までの科目名や別名から入力欄直下の候補を補完する。ネイティブdatalistや科目の選択シートは使わない。Android Chromeで報告された候補の消失・位置ずれへの対策を維持し、入力中のフォーカスを保つ。

詳細は [科目の直接入力と補完](course-autocomplete.md) を正とする。種類と内部の保存形式については本書の前節に従う。
